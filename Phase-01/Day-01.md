# Sorting Problem 


* Input : Sequence of numbers (a1,a2,a3,..........,an)
* Output: Permutation of sequence (a1',a2',a3',.........,an') where a1' <= a2' <= a3'<=.....<=an'

# Why computational time is important ?

* Lets Take a Computer A which executes 10^9 instructions per second
* Computer B takes 10^7 instructions per second

* Task is sort a 10 million numbers 10^7 numbers

* Computer A uses insertion sort and Computer B uses merge sort
* Time complexity of insertion sort : O(n^2)
* Space Complexity of merge sort : O(n^logn)


Time = No of instructions / No of instructions per second

Computer A 
 = 10^14 / 10^9 = 10^5 seconds 

Computer B
* 10^7 log 10^7 / 10^7 = log 10^7 = 23.5 seconds


Even With Powerful machine insertion sort takes 10 power 5 seconds to sort a million numbers while merge sort with less power compute in 23 seconds
